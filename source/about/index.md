## 你好，这里是 PushyTao

这是一个用于记录技术探索、整理实践过程与保存学习笔记的个人博客。

希望这里的每篇文章都能保留足够的上下文：问题从哪里来，尝试过什么，如何确认结果，以及还有哪些尚未解决的部分。内容会随着新的实践逐步积累，也会在需要时修订。

## 从这里开始

- 在[文章归档](/archives/)中按时间浏览。
- 在[专题](/topics/)中寻找相近的主题。
- 通过[Atom 订阅](/atom.xml)获取后续文章。
- 在 [GitHub](https://github.com/PushyTao) 查看公开项目。

## 关于这个站点

站点使用 Hexo 生成静态页面，通过 GitHub Pages 发布。Orbit 是为这个博客制作的主题，采用本地字体栈与 SVG 插图，支持浅色、深色外观以及手机阅读。

目前的两篇起始文章介绍站点与写作流程。它们用于帮助这个空间开始运转，之后可以按照实际的技术实践继续补充。
